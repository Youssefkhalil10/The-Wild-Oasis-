# 🌴 The Wild Oasis

A modern hotel management web application built with **React**.
The Wild Oasis provides a complete dashboard for managing a hotel, including cabins, bookings, guests, and daily hotel activities.

🔗 **Live Demo:**
[The Wild Oasis – Live Demo](https://the-wild-oasis-liart-delta.vercel.app/?utm_source=chatgpt.com)

---

## 📖 About The Project

**The Wild Oasis** is a hotel management application designed to help hotel staff manage their daily operations through a clean and modern dashboard.

The application includes authentication, cabin management, booking management, guest information, hotel statistics, and a responsive user interface with **Dark Mode** support.

The project was built using React and several modern libraries for data fetching, forms, charts, routing, and UI management.

## 🚀 Getting Started

To run the project locally, follow these steps.

### 1. Clone the repository

```bash
git clone https://github.com/Youssefkhalil10/the-wild-oasis.git
```

### 2. Navigate to the project directory

```bash
cd the-wild-oasis
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

---

## 🏗️ Build For Production

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
